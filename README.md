# Twitch Chat Sender Bot

Небольшой бот для Twitch IRC, который только отправляет сообщения. Он не
обрабатывает команды и не отвечает пользователям.

## Возможности

- В режиме `NO` подключается к чату только во время активной трансляции.
- После перехода канала в офлайн останавливает отправку и IRC-соединение.
- В режиме `YES` отправляет сообщения постоянно, в том числе когда канал офлайн.
- Сообщения отправляются по очереди из `messages.txt`; первое сообщение
  отправляется только после `TWITCH_MESSAGE_INTERVAL` секунд.
- При разрыве IRC автоматически подключается снова.

## Настройка

Требуется Python 3.10 или новее. В папке проекта создайте `.env` на основе
`.env.example`:

```powershell
Copy-Item .env.example .env
```

Создайте приложение на
[dev.twitch.tv/console/apps](https://dev.twitch.tv/console/apps) и укажите его
`Client ID`. Для IRC нужен OAuth-токен бота со scopes `chat:read` и
`chat:edit`. В `TWITCH_CHANNEL` указывается логин отслеживаемого канала без
`#`, а в `TWITCH_BOT_USERNAME` логин бота.

Настройка режима:

```dotenv
TWITCH_CHAT_SEND_ALWAYS=NO
```

Допустимы `YES`/`NO`, `ДА`/`НЕТ`, `true`/`false` и `1`/`0`.

В `messages.txt` укажите по одному сообщению на строку. Пустые строки и строки
с `#` в начале игнорируются. Максимальная длина одного сообщения - 500
символов.

## Запуск

```powershell
python bot.py
```

Остановка выполняется через `Ctrl+C`. Логи показывают состояние трансляции,
подключение и отправленные сообщения, но OAuth-токен в логах не выводится.
